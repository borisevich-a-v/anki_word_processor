How to use this tool

1. Prepare your files

  • Put your files into the data folder: {{ data_folder }}.
  • A terms file is a text file with one term per line. Repeated lines, in any letter case, count once.
  • A source text is optional: any text file where your terms occur. When given, example sentences are taken from it.
  • Added a file while the page was open? It shows up in the lists by itself.

2. Make cards

  • Choose the language pair, the terms file and, if you have one, the source text, then press Make cards.
  • First a report appears: how many terms the file has, how many will be processed, and which already have a card (those are skipped, so nothing is made twice).
  • A progress bar shows the term being worked on. Cancel stops after the term in hand; cards already made are kept.
  • When it ends you see how many cards were made and which terms failed (with the reason) or were left for the next run. Run again processes just the terms left.
  • New cards appear in the list below as soon as they are made.

3. Check and correct the cards

  • The list shows the cards of the chosen language pair, oldest first. A green bar on the left marks the cards of the last run.
  • Click or tap a card to select it; Shift-click selects a stretch of cards. Select last run, Select all, Select by id range and Clear help with bigger selections.
  • Double-click or double-tap a field to edit it, or press Enter on a card. Clicking away saves; Enter saves, Tab saves and goes to the next field, Esc cancels. A change that breaks a rule of the language pair is refused with the reason, and the card stays as it was.
  • Edits are saved at once and are still there after a restart.

4. Delete what you do not want

  • Select the cards and press Delete selected. You are asked to confirm and it cannot be undone. The term can be made again by a later run.

5. Export to Anki

  • Select the cards to take, press Export selected and choose where to save the file (some browsers save it to Downloads).
  • In Anki use File → Import and pick that file. Exporting does not change or delete your cards, so you can export again.

Keys

  • Tab goes to the card list; arrows, Home and End move between cards.
  • Space selects or unselects the card in focus; Enter edits its first field; Delete deletes the selected cards (after asking).
  • F1 opens or closes this help; Esc closes it.
